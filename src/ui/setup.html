Rojey POS · Settings

1. Website

If the address changes, type the new one here. Orders waiting on this computer are kept and upload to the new address. Menus, tables and users download from it the next time someone signs in with internet.

2. Printers

Each kitchen on the website (for example Kitchen and Cafe) gets its own KOT printer. The moment an order is placed, each item prints at its own kitchen. Bills and receipts print at the cashier.

Cashier: receipts and bills
Any other kitchen (default KOT printer)

3. Taxes

Off unless an admin turns it on. When an admin switches taxes on or off on the website, this till follows by itself.

4. Updates

New versions come from GitHub. An admin installs them with the update button at the top of the POS screen.

5. Other

Orders that are still waiting to upload are never deleted. Only orders the website has confirmed are removed after the days above.

Open the data folder (database and log)
